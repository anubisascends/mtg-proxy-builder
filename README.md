# MTG Proxy Builder

A Windows desktop application for creating printable PDFs of trading card game proxy cards. Supports Magic: The Gathering, Pokemon, Yu-Gi-Oh!, and many other TCGs with professional print-ready output including bleed margins, cutting guides, and duplex printing.

> **Note:** This application was built entirely with AI (Claude) as an experiment to see how quickly a fully featured desktop application could be created under the direction of an experienced developer. All architecture decisions, feature requirements, UX direction, and quality standards were driven by the developer; all code was generated by the AI. The project serves as a real-world test of AI-assisted software development at scale.

## Features

### Card Search & Import
- **Scryfall Integration** -- search by name, type, color, mana cost, set, rarity, artist, format legality, and more using Scryfall's full query syntax
- **Scryfall Advanced Search** -- visual query builder with dropdowns for all Scryfall filter fields
- **MPCFill Integration** -- search community-contributed high-DPI proxy art from MPCFill.com with source management and favorites
- **Moxfield Import** -- paste a Moxfield deck URL to import an entire deck list with artwork
- **Archidekt Import** -- paste an Archidekt deck URL to import a deck list (auto-detected from URL)
- **Local Files** -- add card images from your computer
- **Double-click to add** -- double-click any search result to immediately add it

### Visual Page Editor
- **Multi-page preview** -- all pages displayed vertically in a scrollable, zoomable canvas
- **Drag and drop** -- reorder cards across pages by dragging
- **Multi-select** -- Ctrl+Click to select multiple cards, or click empty space to deselect
- **Right-click menu** -- duplicate, delete, flip (front/back) for selected or hovered cards
- **Flip preview** -- view back artwork on the canvas; flip individual cards, selected cards, or all at once
- **Zoom** -- Ctrl+Mouse Wheel, +/- buttons, Fit to Width, and 1:1 reset (15% to 300%)
- **Keyboard shortcuts** -- Ctrl+Z undo, Ctrl+Y redo, Escape to deselect

### Art Selection
- **Art Selector Dialog** -- click "Select Art..." on any card to browse all available artwork from Scryfall (all printings) and MPCFill (community art) in a thumbnail grid
- **Back Art Selector** -- choose card backs from Scryfall originals, a persistent library, or custom files
- **Bulk apply** -- apply art to all cards with the same name, or apply back art to all cards without one
- **MPCFill Source Manager** -- browse 271+ community art sources, favorite your preferred ones, and filter searches to favorites only

### Print & PDF
- **Card size presets** -- built-in sizes for MTG, Pokemon, Yu-Gi-Oh!, Lorcana, Flesh and Blood, KeyForge, and 20+ other TCGs, plus custom dimensions
- **Page presets** -- A4, A3, Letter, Legal, Tabloid with landscape toggle
- **Bleed extension** -- edge pixels stretched outward (not just image resize) for clean cutting
- **Cutting guides** -- crop marks extending to page edges for precise cutting
- **Print modes** -- Duplex (interleaved front/back with mirrored columns), Fronts Only, or Backs Only
- **Auto-centering** -- margins automatically adjust to center the card grid when dimensions change
- **Grid override** -- manually set columns and rows, or let the app auto-fit

### Project Management
- **Portable project files** -- `.mtgproj` files are self-contained ZIP archives bundling all artwork; share them freely between computers
- **Undo / Redo** -- 50-level undo stack covering all card operations (Ctrl+Z / Ctrl+Y)
- **Sort & Filter** -- filter the card list by name, type, rarity, color; sort by CMC, name, set, artist, and more; permanently apply sort order to the project
- **Full card metadata** -- stores mana cost, type line, oracle text, rarity, colors, set, artist, power/toughness, keywords from Scryfall

### UX
- **Dark theme** -- modern dark UI inspired by VS Code
- **Busy spinner** -- animated overlay with step-by-step progress messages during network operations
- **No screen flashing** -- bulk imports batch-add cards to prevent rapid redraws
- **Async image loading** -- card images load on a background thread; cached in memory for instant redraws
- **Cache management** -- automatic cleanup of temp files on startup; manual "Clear Cache" button with size display

## Building & Running

### Prerequisites
- .NET SDK 10.0 or later
- Windows 10/11
- curl (ships with Windows 10+, used for Moxfield API)

### Build
```bash
cd mtg-proxy-builder
dotnet build
```

### Run
```bash
cd MTGProxyBuilder.UI
dotnet run
```

## Usage Guide

### Getting Started
1. Launch the application
2. Enter a project name in the toolbar
3. Add cards using one of the methods below

### Adding Cards

**From Scryfall:**
1. In the Search tab (right panel), make sure "Scryfall" is selected
2. Type a card name and press Enter or click Search
3. Click a result to see a preview, or double-click to add it immediately
4. Use "Advanced Search" for filters (type, color, CMC, rarity, set, format, etc.)

**From MPCFill:**
1. Select "MPCFill" in the Search tab
2. Search for a card name -- results show community art with thumbnails, source, and DPI
3. Use the inline filters: name filter, minimum DPI, fuzzy/exact toggle
4. Click "Sources..." to manage and favorite art sources
5. Check "Favs only" to limit searches to your favorite sources

**From a Deck List:**
1. Scroll down in the Search tab to "Import Deck"
2. Paste a Moxfield or Archidekt URL and press Enter
3. The app auto-detects the site, fetches the deck, and downloads all artwork with progress updates

**From Files:**
1. Click "+ File" in the toolbar
2. Select one or more image files (PNG, JPG, BMP)

### Working on Pages

**Selecting cards:**
- Click a card to select it (blue highlight)
- Ctrl+Click to add/remove from selection
- Click empty space or press Escape to deselect

**Reordering:**
- Drag a card to a new position on any page
- The print order matches what you see on screen

**Right-click menu:**
- Duplicate / Delete (single card or all selected)
- Flip to see back artwork
- Flip All to preview the back side of every card

**Changing artwork:**
- Select a card, go to the Card tab
- Click "Select Art..." to browse all Scryfall printings + MPCFill art in a visual grid
- Click "Select Card Back..." to choose back artwork from library, Scryfall, or a file
- Check "Apply to all [card name]" to update every copy at once

**Zoom:**
- Ctrl+Mouse Wheel to zoom in/out
- Use +/- buttons, "Fit", or "1:1" in the bottom-right corner

### Configuring Layout

In the Layout tab:
- **Page Size** -- A4, Letter, etc. with landscape toggle
- **Card Size** -- pick a TCG preset or enter custom dimensions
- **Bleed** -- set bleed width in mm (edge pixels are extended, not stretched)
- **Cutting Guides** -- toggle crop marks that extend to page edges
- **Grid** -- override columns/rows or leave blank for auto-fit
- **Print Mode** -- Duplex, Fronts Only, or Backs Only

### Exporting PDF
1. Click "Export PDF" in the toolbar
2. Choose a save location
3. The PDF includes bleed-extended images and cutting guides (if enabled)
4. For duplex: front and back pages are interleaved with mirrored columns

### Saving & Loading Projects
- **Save:** Ctrl+S or click "Save" -- creates a `.mtgproj` ZIP file containing all artwork
- **Open:** Click "Open" -- extracts and loads the project with all images intact
- Projects are fully portable -- share the single file between computers

### Undo / Redo
- Ctrl+Z to undo, Ctrl+Y to redo (up to 50 levels)
- Covers all card operations: add, remove, reorder, art changes, bulk operations

## Troubleshooting

### Application won't start
- Ensure .NET 10.0+ SDK is installed: `dotnet --version`
- Rebuild: `dotnet clean && dotnet build`

### Scryfall search returns errors
- Check internet connection
- Scryfall rate-limits to ~10 requests/second; the app respects this automatically
- 400 errors usually mean the `Accept: application/json` header is missing (should be set automatically)

### MPCFill search returns no results
- The app needs to fetch all 271 sources on first search; ensure you're online
- Check "Favs only" isn't checked with no favorites set
- Try unchecking "Fuzzy" for exact name matches

### Moxfield import fails with 403
- Moxfield uses Cloudflare protection; the app uses curl to bypass this
- Ensure curl is available on your system (ships with Windows 10+)
- Private decks cannot be imported

### Screen flashing during import
- This should not happen; deck imports batch-add all cards at once
- If it does, check that you're running the latest build

### Cache using too much disk space
- Go to the Layout tab and check the "STORAGE" section for current cache size
- Click "Clear Cache" to remove all downloaded images (they'll re-download as needed)
- Extracted project images and bleed cache are automatically cleaned on startup
