# TCG Proxy Builder

A Windows desktop application for creating printable PDFs of trading card game proxy cards. Supports Magic: The Gathering, Pokemon, Yu-Gi-Oh!, Riftbound, and 20+ other TCGs with professional print-ready output including bleed margins, cutting guides, card outlines, and duplex printing.

> **Note:** This application was built entirely with AI (Claude) as an experiment to see how quickly a fully featured desktop application could be created under the direction of an experienced developer. All architecture decisions, feature requirements, UX direction, and quality standards were driven by the developer; all code was generated by the AI. The project serves as a real-world test of AI-assisted software development at scale.

## Download

1. Go to the [Releases](../../releases) page
2. Download the latest `TCGProxyBuilder-vX.X.X-win-x64.zip`
3. Extract the ZIP to any folder
4. Run `tcg-proxy-builder.exe` — no installation or .NET runtime required

## Feature Highlights

- **Multi-source card search** — Scryfall (full query syntax + advanced search) and MPCFill (271+ community art sources with DPI filtering)
- **Deck import** — paste a URL from Moxfield, Archidekt, or Piltover Archive (Riftbound) to auto-import an entire deck
- **Visual page editor** — multi-page canvas with drag-drop, multi-select, flip preview, zoom/pan, and overlay text
- **Art selector** — browse all printings from Scryfall and community art from MPCFill with progressive loading, pill-based filters, and a zoomable preview
- **Persistent art libraries** — front and back art libraries with thumbnail grids, search, export/import, and move-to-folder
- **Professional print output** — bleed extension, cutting guides, card outlines (customizable color/style/alignment), and Silhouette Cameo registration marks with SVG cut lines
- **25+ TCG presets** — built-in card sizes from MTG to Yu-Gi-Oh! to Riftbound
- **Portable projects** — `.mtgproj` ZIP archives bundle all artwork for sharing
- **Clipboard paste** — Ctrl+V to paste images directly or auto-detect Piltover Archive deck URLs

## Tech Stack

| Component | Technology |
|-----------|-----------|
| UI Framework | WPF (.NET 10.0-windows) |
| SVG Rendering | Svg.Skia 2.0 |
| Mana/Set Symbols | Embedded SVGs ([CardConjurer](https://github.com/MrTeferi/cardconjurer) mana, [mtg-vectors](https://github.com/Investigamer/mtg-vectors) sets) |
| PDF Generation | PdfSharp 6.1.1 |
| Image Processing | SkiaSharp 3.119.0 |
| JSON Serialization | Newtonsoft.Json 13.0.3 |
| Card Data | Scryfall API |
| Proxy Art | MPCFill.com API |
| Deck Import | Moxfield API, Archidekt API, Piltover Archive |
| Logging | Serilog 4.2 + Serilog.Sinks.File 6.0 |
| Architecture | MVVM (Shell + per-project ViewModels) |
